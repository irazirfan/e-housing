# E-housing




**To run ng project**
```
set NODE_OPTIONS=--openssl-legacy-provider (OpenSSL 3 compatibility issue)
ng serve
```


**To run dotnet project**
```
dotnet run
```


**To install dotnet ef tool in vscode**
```
dotnet tool install --global dotnet-ef
```


**To create db for first time**
```
dotnet ef database update
```

## Stack Used

Node: 12.22.12
Angular: 11.2.14
DotNet: 8.0.0
